# Bibliography of Visa Large Transaction Model Papers

A running list of Visa-published academic research on Foundation/Large Transaction Models for payments data.

|Paper|Authors|Date|Venue|Link|Summary|
|-|-|-|-|-|-|
|**Towards a Foundation Purchasing Model: Pretrained Generative Autoregression on Transaction Sequences** |Piotr Skalski, David Sutton, Stuart Burrell, Iker Perez, Jason Wong|Nov 2023|ACM ICAIF 2023 (pp. 141-149)|[arXiv:2401.01641](https://arxiv.org/abs/2401.01641)|Introduces a generative pretraining method (NPPR) for contextualized embeddings of financial transactions, pretrained on 5.1B transactions from 180 issuing banks; shows up to 140% uplift over hand-engineered features on card fraud detection.|
|**TransactionGPT: Toward Foundational Transaction Modeling**|Yingtong Dou, Zhimeng Jiang, Tianyi Zhang, Mingzhi Hu, Zhichao Xu, Shubham Jain, Uday Singh Saini, Xiran Fan, Jiarui Sun, Menghai Pan, Junpeng Wang, Xin Dai, Liang Wang, Chin-Chia Michael Yeh, Yujie Fan, Yan Zheng, Vineeth Rakesh, Huiyuan Chen, Guanchu Wang, Mangesh Bendre, Zhongfang Zhuang, Xiaoting Li, Prince Aboagye, Vivian Lai, Minghua Xu, Hao Yang, Yiwei Cai, Mahashweta Das, Yuzhong Chen (29 authors)|Nov 2025|KDD 2026|[arXiv:2511.08939](https://arxiv.org/abs/2511.08939)|A Foundation Model for consumer transaction data using a novel 3D-Transformer architecture, trained on billion-scale transactions; outperforms production baselines on anomaly detection and fine-tuned LLMs on predictive accuracy, with faster training/inference.|
|**TREASURE: The Visa Payment Foundation Model for High-Volume Transaction Understanding**|Chin-Chia Michael Yeh, Uday Singh Saini, Xin Dai, Xiran Fan, Shubham Jain, Yujie Fan, Jiarui Sun, Junpeng Wang, Menghai Pan, Yingtong Dou, Yuzhong Chen, Vineeth Rakesh, Liang Wang, Yan Zheng, Mahashweta Das|Nov 2025|KDD 2026|[arXiv:2511.19693](https://arxiv.org/abs/2511.19693)|Transformer-based Foundation Model capturing consumer behavior and payment network signals, with specialized handling for heterogeneous attribute types and efficient high-cardinality categorical prediction; improves abnormal behavior detection by 111% and recommendation performance by 104% over production systems.|
|**Enhancing Foundation Models in Transaction Understanding with LLM-based Sentence Embeddings**|Xiran Fan, Zhimeng Jiang, Chin-Chia Michael Yeh, Yuzhong Chen, Yingtong Dou, Menghai Pan, Yan Zheng|Dec 2025|EMNLP 2025|[arXiv:2601.05271](https://arxiv.org/abs/2601.05271)|Uses LLM-generated sentence embeddings to semantically initialize smaller transaction models, replacing index-based categorical representations; introduces multi-source data enrichment and a "one-word constraint principle" for embedding standardization.|
|**MINT: A Universal Zero-Shot Predictor for Transaction Data**|Parameswaran Kamalaruban, Viktor Drobnyi, Maeve Madigan, Julia Rozanova, David Sutton, Stuart Burrell|Aug 2026|arXiv preprint|[arXiv:2608.14198](https://arxiv.org/abs/2608.14198)|Links a transaction-sequence encoder to an LLM via lightweight embedding injection, transaction-language alignment, and instruction tuning; achieves leading zero-shot predictive QA results while reducing compute versus text-serialization approaches.|

* Ordered chronologically by submission date.
